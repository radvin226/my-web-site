🚀 Radvin Framework

Async Bot Framework مشابه Telegram Bot Libraries

نصب

pip install radvin

شروع سریع

from radvin import ( Application, CommandHandler ) TOKEN = "BOT_TOKEN" async def start(update, context): await update.message.reply_text( "سلام از Radvin 🚀" ) app = ( Application .builder() .token(TOKEN) .build() ) app.add_handler( CommandHandler( "start", start ) ) app.run_polling()

ارسال پیام

await update.message.reply_text( "Hello Radvin" )

ارسال عکس

await update.message.reply_photo( "https://example.com/image.jpg", caption="Radvin" )

دکمه Inline

keyboard = InlineKeyboardMarkup([ [ InlineKeyboardButton( "Website", url="https://example.com" ) ] ]) await update.message.reply_text( "Click", reply_markup=keyboard )

Handlers

CommandHandler برای دستورات

MessageHandler برای پیام‌ها

app.add_handler( MessageHandler( filters.TEXT, echo ) )
