کتابخانه حرفه‌ای ساخت ربات با پایتون

شروع کنید 🚀

📦 نصب

نصب MyBot از PyPI:

pip install mybot

🚀 شروع سریع

from mybot import Application app = Application.builder()\ .token("TOKEN")\ .build() app.run_polling()

🎛️ سیستم دکمه‌ها

ساخت دکمه‌های تعاملی برای کاربران.

InlineKeyboardButton( text="Click", callback_data="test" )

📸 ارسال عکس

ارسال عکس با Media ID:

await bot.send_photo( chat_id=user_id, photo="MEDIA_ID" )

⚡ قابلیت‌ها

  • ساخت ربات سریع
  • مدیریت پیام‌ها
  • دکمه‌های حرفه‌ای
  • مدیریت مدیا
  • Callback Query
  • API ساده

🔐 امنیت

توکن ربات را امن نگه دارید.
هیچ وقت آن را در کد عمومی منتشر نکنید.

📚 مثال کامل

from mybot import Application TOKEN="YOUR_TOKEN" app = Application.builder()\ .token(TOKEN)\ .build() print("Bot Started 🚀") app.run_polling()
