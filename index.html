🤖 MyBot چیست؟

MyBot یک فریم‌ورک مدرن پایتون برای ساخت ربات‌های حرفه‌ای است. هدف MyBot ساده کردن ساخت ربات‌های سریع، امن و قابل توسعه است.

  • ⚡ سرعت بالا
  • 🧩 سیستم Handler قدرتمند
  • 📸 پشتیبانی Media
  • 🎛 دکمه‌های تعاملی
  • 🔒 مدیریت خطا

📦 Installation

نصب از PyPI: 


pip install mybot

آپدیت کردن: 


pip install --upgrade mybot

🚀 Quick Start

اولین ربات خود را بسازید: 



from mybot import Application


app = Application.builder()\
.token("TOKEN")\
.build()



app.run_polling()

🔑 Token

توکن ربات خود را از Bot Creator دریافت کنید و در برنامه قرار دهید. 



TOKEN = "YOUR_BOT_TOKEN"

🧩 Handler System

Handler ها رفتارهای ربات را کنترل می‌کنند.

Handler کاربرد
CommandHandler دستورهایی مثل /start
MessageHandler دریافت پیام کاربر
CallbackHandler دکمه‌های Inline 


app.add_handler(

CommandHandler(
"start",
start
)

)

⚙ API Reference

reply_text()

ارسال پیام متنی 



await message.reply_text(
"Hello MyBot"
)

send_photo()

ارسال تصویر با Media ID 



await bot.send_photo(

chat_id=user_id,

photo="MEDIA_ID"

)

edit_message()

ویرایش پیام ارسال شده 



await bot.edit_message(

message_id=id,

text="New Text"

)

📸 Media System

برای فایل‌ها می‌توانید از Media ID استفاده کنید. 



PHOTO_ID =
"8281b0fb-1bd4-43fa-bca0-59364e99ea7a"



await bot.send_photo(

chat_id=user,

photo=PHOTO_ID

)

🎛 Keyboard API

ساخت دکمه: 



button = InlineKeyboardButton(

text="Click",

callback_data="test"

)


keyboard = InlineKeyboardMarkup(

[
[button]
]

)

💻 Examples

یک ربات ساده: 



from mybot import Application


async def start(update, context):

    await update.message.reply_text(
        "سلام 👋 به MyBot خوش آمدید"
    )



app = Application.builder()\
.token("TOKEN")\
.build()



app.run_polling()

🛡 Error Handling

مدیریت خطا برای جلوگیری از توقف ربات. 



try:

    app.run_polling()


except Exception as error:

    print(error)
